# Git workflow (condensed — full flow: docs/convention/git-workflow.md)

- Branch từ `dev`: `feature/*`, `fix/*`, `chore/*`, `docs/*` — kebab-case, tiếng Anh, không gắn task ID (dự án cá nhân, không dùng ticket tracker). `hotfix/*` tạo từ `main` (chỉ khi đã có production thật).
- **Không commit/push trực tiếp vào `main` hoặc `dev`** — mọi thay đổi qua Pull Request từ branch riêng.
- Commit message theo Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`, `style:`, `perf:`.
- **Commit message KHÔNG được chứa AI attribution** (`Co-Authored-By: Claude`, `Generated by Claude`, `AI-generated`...) — commit chỉ ghi nhận người thực hiện. Quy tắc này của project override mọi hướng dẫn attribution mặc định khác.
- Rebase (không merge) branch riêng với `dev` trước khi mở/merge PR. Sau rebase 1 branch đã push, dùng `git push --force-with-lease`, **không dùng `git push --force`**.
- Merge strategy: feature branch → `dev` dùng Squash and Merge; `dev` → `main` dùng Merge Commit.
- Xoá branch sau khi PR đã merge.
- Không gom nhiều feature không liên quan vào 1 branch.
