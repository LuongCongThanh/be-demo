# Convention — mục lục & thứ tự đọc

Thư mục này chứa các convention **chung, generic** cho toàn bộ ecommerce project — mô tả _cách_ viết code (naming, cấu trúc, config, error handling, API flow, schema), không phải business rule của 1 resource cụ thể (business rule nằm ở [`../business/`](../business/), thiết kế từng module ở [`../architecture/modules/`](../architecture/modules/)).

Mọi module trong `src/modules` dùng **một** kiến trúc Hexagonal, không có module ngoại lệ ([ADR 0015](../adr/0015-one-layered-architecture-for-every-module.md)). [module-architecture-conventions.md](module-architecture-conventions.md) là nguồn chuẩn duy nhất cho phân tầng, Port/adapter, DI, lỗi, transaction và ranh giới module; các convention khác chỉ dẫn chiếu sang đó, không tạo quy tắc kiến trúc song song. Module chưa chuyển đổi xem mục _Migration status_ trong [`.claude/rules/module-architecture.md`](../../.claude/rules/module-architecture.md).

Đọc theo đúng thứ tự dưới đây nếu bạn mới vào project — mỗi mục sau dựa trên/tham chiếu ngược lại mục trước:
