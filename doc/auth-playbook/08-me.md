# 08 — `GET /auth/me`

> Trước khi làm file này: xong [07-guards.md](./07-guards.md) — `JwtAuthGuard` và `@CurrentUser()` phải hoạt động trước. Tham chiếu chung (Response DTO...): [00-overview.md](./00-overview.md).

File này ngắn — chủ yếu là ghép lại những gì đã có sẵn từ các file trước (`JwtAuthGuard`, `@CurrentUser()`, `AuthUserResponseDto`), không có khái niệm mới nào cần học thêm.

⚠️ `AuthUserResponseDto` đã được tạo ở [05-login.md](./05-login.md), phần Bước "LoginDto + Response DTOs" (`src/auth/dto/auth-user-response.dto.ts`) — ở đây chỉ **import lại**, không tạo trùng file/class.

Việc cần làm chỉ có 2 phần. Trước hết, thêm method `getMe` vào `AuthService` — chỉ query rồi map sang DTO đã có sẵn, không có business logic phức tạp:

```ts
// src/auth/services/auth.service.ts (thêm import + method vào class đã có)
import { AuthUserResponseDto } from '../dto/auth-user-response.dto';

// ... trong class AuthService

async getMe(userId: string): Promise<AuthUserResponseDto> {
  const user = await this.prisma.user.findUniqueOrThrow({
    where: { id: userId },
    include: { userRoles: { include: { role: true } } },
  });

  // Map thủ công sang DTO allow-list — KHÔNG return thẳng `user` (có passwordHash).
  return {
    id: user.id,
    email: user.email,
    fullName: user.fullName ?? null,
    roles: user.userRoles.map((r) => r.role.name),
    emailVerified: user.emailVerifiedAt !== null,
  };
}
```

⚠️ Tên relation (`user.userRoles`, `r.role.name`) và field (`fullName`, `emailVerifiedAt`) phải khớp `prisma/schema.prisma` — đối chiếu lại trước khi paste.

Rồi thêm route vào `AuthController`:

```ts
// src/auth/auth.controller.ts (thêm import + route vào class đã có)
import { Get, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from './guards/jwt-auth.guard';
import { CurrentUser } from './decorators/current-user.decorator';
import { JwtPayload } from './strategies/jwt.strategy';
import { AuthUserResponseDto } from './dto/auth-user-response.dto';

// ... trong class AuthController

@UseGuards(JwtAuthGuard)
@Get('me')
getMe(@CurrentUser() user: JwtPayload): Promise<AuthUserResponseDto> {
  return this.authService.getMe(user.sub);
}
```

Xong rồi — gọi thử với 1 access token hợp lệ (từ bước login), bạn sẽ nhận đúng thông tin user hiện tại. Bỏ header `Authorization` đi và gọi lại, bạn sẽ nhận `401` (do `JwtAuthGuard` chặn, không phải do code trong `getMe()` bạn vừa viết — nó không bao giờ chạy tới trong trường hợp đó). Xem kỹ response trả về để chắc chắn không có field nào rò rỉ ngoài ý muốn — không `passwordHash`, không `tokenHash`, không field DB nội bộ nào khác.
