# 08 — `GET /auth/me`

> ⬅️ Trước khi làm file này: xong [07-guards.md](./07-guards.md) (`JwtAuthGuard` + `@CurrentUser()` đã hoạt động).
> 📚 Tham chiếu chung (Response DTO...): [00-overview.md](./00-overview.md).

**Goal:** Trả thông tin user hiện tại, không leak field nhạy cảm.

File này ngắn — chủ yếu là ghép lại những gì đã có sẵn từ các file trước (`JwtAuthGuard`, `@CurrentUser()`, `AuthUserResponseDto`), không có khái niệm mới.

> ⚠️ `AuthUserResponseDto` **đã được tạo ở [05-login.md § STEP 10.2](./05-login.md)** (`src/auth/dto/auth-user-response.dto.ts`) — file này chỉ **import lại**, không tạo trùng file/class.

**Files:** `src/auth/services/auth.service.ts`, `src/auth/auth.controller.ts` (không có file DTO mới)

**Implementation:**

1. Thêm method `getMe` vào `AuthService` — chỉ query + map sang DTO đã có sẵn (`AuthUserResponseDto`, import từ `../dto/auth-user-response.dto`), không có business logic phức tạp:

   ```ts
   // src/auth/services/auth.service.ts (thêm import + method vào class đã có)
   import { AuthUserResponseDto } from '../dto/auth-user-response.dto';

   // ... trong class AuthService

   async getMe(userId: string): Promise<AuthUserResponseDto> {
     const user = await this.prisma.user.findUniqueOrThrow({
       where: { id: userId },
       include: { roles: { include: { role: true } } },
     });

     // Map thủ công sang DTO allow-list — KHÔNG return thẳng `user` (có passwordHash).
     return {
       id: user.id,
       email: user.email,
       fullName: user.fullName ?? null,
       roles: user.roles.map((r) => r.role.name),
       emailVerified: user.emailVerifiedAt !== null,
     };
   }
   ```

   > ⚠️ Tên relation (`user.roles`, `r.role.name`) và field (`fullName`, `emailVerifiedAt`) phải khớp `prisma/schema.prisma` — đối chiếu lại trước khi paste.

2. Thêm route vào `AuthController`:

   ```ts
   // src/auth/auth.controller.ts (thêm import + route vào class đã có)
   import { Get, UseGuards } from '@nestjs/common';
   import { JwtAuthGuard } from './guards/jwt-auth.guard';
   import { CurrentUser } from './decorators/current-user.decorator';
   import { JwtPayload } from './strategies/jwt.strategy';
   import { AuthUserResponseDto } from './dto/auth-user-response.dto';

   // ... trong class AuthController

   @UseGuards(JwtAuthGuard)
   @Get('me')
   getMe(@CurrentUser() user: JwtPayload): Promise<AuthUserResponseDto> {
     return this.authService.getMe(user.sub);
   }
   ```

**Acceptance Criteria:**

- [ ] Có token hợp lệ → trả đúng thông tin user.
- [ ] Không có token → 401.
- [ ] Response không chứa `passwordHash`, `tokenHash`, hay field DB nội bộ khác.
